# AttendX

A modern offline-first attendance tracking app built for college students using React Native and Expo.

## Features

* Track subject-wise attendance
* Weekly timetable management
* Attendance analytics and progress visualization
* Calendar-based attendance history
* Data backup and restore
* Dark & Light mode support
* Fully offline with local storage

## Tech Stack

* React Native 0.81
* Expo SDK 54
* React Navigation
* AsyncStorage
* React Native SVG
* Expo File System
* Expo Haptics
